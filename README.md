FeatherCrawl 是一款使用了 **WinHTTP** 的网络请求库。仅需一个头文件实现在 C++ 中进行网页抓取。

此项目正在积极开发中，欢迎关注。

---

## 特性

- 架构：WinHTTP 
- 调用简单，仅需 `#include "feathercrawl.h"`
- C++11 及以上，Windows 10/11 原生支持
