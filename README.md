FeatherCrawl 是一款融合了 **WinHTTP** 的高效网络请求与 **Miniblink M108** 的完整 JS 渲染引擎。一个头文件 + 一个 DLL，实现在 C++ 中进行静态与动态网页抓取。

此项目正在积极开发中，欢迎关注。

---

## 特性

- 双引擎架构：WinHTTP + Miniblink M108 (Chromium)
- 支持 JavaScript 渲染、无头模式、HTTPS
- 调用简单，仅需 `#include "feathercrawl.h"`
- C++11 及以上，Windows 10/11 原生支持
